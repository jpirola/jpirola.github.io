Política de Privacidade — Joao Pirola Automacoes

Este aplicativo é usado exclusivamente pelo seu titular, em sua própria conta Google, para automações pessoais.

Os dados acessados pelas APIs do Google (como o Gmail) são processados apenas no servidor pessoal do titular, não são vendidos, compartilhados nem transferidos a terceiros, e não são usados para publicidade.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
